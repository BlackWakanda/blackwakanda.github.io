# Black Wakanda Portfolio

This repository hosts your personal portfolio site on GitHub Pages.

## Live URL

Your site URL will be:

- `https://blackwakanda.github.io/`

## Step 1: Deploy Your Portfolio (GitHub Pages)

If this repository is already named `blackwakanda.github.io`, publishing is straightforward.

1. Push this repo to GitHub on the `main` branch.
2. Go to repository `Settings` -> `Pages`.
3. Under `Build and deployment`, choose:
	- `Source`: `Deploy from a branch`
	- `Branch`: `main`
	- `Folder`: `/ (root)`
4. Save and wait 1-3 minutes.
5. Open `https://blackwakanda.github.io/`.

GitHub Pages guide: https://docs.github.com/en/pages
